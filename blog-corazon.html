Narrando el suspenso: Código y Arte

Composición Plástica e Interactividad

Para este proyecto de "Libro Álbum Interactivos", el reto fue integrar el código con una atmósfera de suspense constante.

Sincronización de Audio y Visuales

Implementamos lógica en HTML5, CSS3 Y JavaScript para asegurar que cada transición de página fuera acompañada por una atmósfera sonora envolvente. La estética minimalista oscura ayuda a que el usuario se sumerja totalmente en la historia.

VER PROYECTO

Trabajado bajo la guía de la Luis Enrique Ramos Barbour, este proyecto representa un puente entre la programación front-end y la narrativa visual.
