CASE STUDY // INTERACTIVE NARRATIVE

Narrativa:
El Corazón del Asesino

Diseño de un libro álbum interactivo que fusiona código JavaScript con una atmósfera de suspenso inmersiva.

VER PROYECTO
/* ESTRATEGIA: RETO Y SOLUCIÓN (Análisis del proyecto) */

The Challenge

El reto principal fue integrar la narrativa de suspenso con la interactividad técnica, logrando que el código no interrumpiera la inmersión del lector.

"La atmósfera debe sentirse tensa desde el primer clic; el usuario debe ser parte del misterio."

— Concepto Narrativo

The Solution

Implementamos un sistema de carga progresiva y sincronización de audio que responde a las acciones del usuario, aumentando la tensión visual.
